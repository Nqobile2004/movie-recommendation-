# Movie Recommendation System

A movie recommendation engine built with Python that uses collaborative and content-based filtering.

## Features
- **Collaborative Filtering:** SVD Recommender
- **Content-Based:** Recommends movies based on genre/content similarity
- **Evaluation:** Functions to evaluate recommender accuracy
- **Sample Data:** Synthetic MovieLens data generator for testing

## Project Structure
- `collaborative/` - SVD collaborative filtering model
- `content based/` - Content-based recommender class
- `evaluate/` - Evaluation metrics for the system
- `sample data/` - Synthetic data generation

## How to Run
```bash
pip install -r requirements.txt
python main.py
